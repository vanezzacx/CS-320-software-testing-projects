# CS-320-software-testing-projects

- How can I ensure that my code, program, or software is functional and secure?
  To ensure that my software is functional and secure, I focused on testing and validation. I used JUnit for unit testing to check both valid and invalid inputs, ensuring the program meets all requirements and works as intended. I also added input validation to prevent errors such as null values or incorrect formats. Security is important because it helps protect user information.
  
- How do I interpret user needs and incorporate them into a program?
  I interpret user needs by ensuring I follow the requirements and treat them like a checklist. Each requirement ensures the program behaves as intended.
  
- How do I approach designing software?
  I approach designing software by starting with the requirements and breaking down each task into smaller parts. I try to remain organized and test each class to ensure each part of the code works. I also make sure the design of my code is easy to maintain by keeping it readable and well-structured. Testing plays a big role in my design process because it helps confirm that everything works as intended.
